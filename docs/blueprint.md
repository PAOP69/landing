# **App Name**: PulseDash Edu

## Core Features:

- Live Performance Dashboard: A centralized hub featuring real-time cards for academic progress metrics and overall student standing.
- Course Mastery Tracker: Visual indicators and progress bars showing the percentage of completion for all active courses.
- Historical Trend Visualizer: Interactive weekly and monthly performance graphs to monitor academic consistency over time.
- AI Study Schedule Optimizer Tool: A generative tool that reasons over your study habits and completion rates to suggest the most effective study windows for peak retention.
- Task & Milestone Registry: Integrated lists for pending assignments and recent achievements to keep students motivated and organized.
- Rapid Access Command Bar: Floating buttons for immediate navigation to current classes, assignment submissions, and grading records.
- Global Data Sync Engine: Robust background handling to ensure all educational metrics and tasks are synchronized across sessions.

## Style Guidelines:

- The primary identity uses a clinical palette including Dark Petrol (#256279) for trust and Vibrant Cyan (#00B2CA) for accents. These analogous cool tones reflect professional clarity and mental focus.
- High-contrast CTAs are styled in Warm Orange (#F9B252) to create urgency, set against a Soft Mint (#B9DED6) or White background.
- Headlines use 'Montserrat' for a bold uppercase aesthetic, while body text uses 'Open Sans' or 'Segoe UI' for a standard reading experience. Note: currently only Google Fonts are supported.
- A fluid grid of 2-4 columns featuring asymmetrically designed cards and horizontal color blocks for a rhythmic visual hierarchy.
- Minimalist line-art icons that use contrasting primary colors and are often encased in subtle circular frames.
- Smooth card transitions with subtle float effects (8px-12px rounded borders) and soft diffused shadows when focused.
